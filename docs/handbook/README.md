# Handbook

The course handbook is **`Songdo_Edge_Intelligence_Handbook.pdf`** (11 pages) by Prof. Mehdi Pirahandeh.
It belongs at the repository root, as in the course README's file layout.

It is the instructor's document, and this repository is public, so the PDF is **not committed**
(it is listed in `.gitignore`). To complete the layout locally or in the submission ZIP, copy the
PDF you downloaded from the course page to the repository root.

The XeLaTeX source of the handbook is the instructor's and is not distributed to students.

Where each handbook requirement is implemented: see the "Requirement map" section of the
top-level `README.md`.
